## 一、总体建模路线

先确认附件结构及目标（实际速率、MCS 类别或速率档位）；解析复数信道状态信息 CSI，检查信道矩阵维度、噪声单位、时间配对；构建防止相邻测量泄漏的训练/验证划分。首先完成题设 EESM 可解释模型；随后利用频域衰落和 MIMO 空间结构特征训练轻量梯度提升树，比较并考虑 EESM 残差修正；最后在 TxBF 场景加入预编码/奇异值信息训练专用模型。三个问题使用一致的数据管线和严格一致的评估协议。

## 二、数据检查与物理预处理

1. 对压缩包内各文件生成清单，核对列名、样本量、类型、缺失比例、标签单位、TxBF 取值、终端或采集区段标识、CSI 时间及速率测量时间；保留原始行号 `sample_id`。
2. 将复数 CSI 列解析为 `H[n,k]∈C^(N_r×N_t)`；校验每条样本的天线通道数和子载波长度一致。公开资料出现过 2×4 天线及 122 个子载波的候选描述，实际以原题和真实数据形状为准。不可对原始字符串使用无限制 `eval`。
3. 噪声如果以 dBm 表示，先转换为线性功率：`P_mW=10^(P_dBm/10)`，`P_W=10^((P_dBm−30)/10)`。SINR 若为 dB，须先转换到线性域后才能代入 EESM。CSI 的功率归一化、每流功率和每载波噪声应按题设统一，不能凭空假设。
4. 统计 `Δt=|t_CSI−t_rate|`，检查时间不对齐引发的噪声。优先按终端、采集段或时间块分组切分有标签数据，防止近邻帧随机切分造成信息泄漏。标准化、插补和目标校准仅在训练折拟合。
5. 画标签直方图、TxBF 比例、频点信道质量热图、奇异值分布、速率与等效 SINR 散点图；检查异常值后再选择修复办法。

## 三、问题一：关闭 TxBF，建立并拟合 EESM

**分析**：不同子载波可能发生强弱不均的频率选择性衰落，简单算术平均丢失弱频点影响。需要先根据题目指定的 CSI、功率、噪声和检测模型计算每个子载波的线性 SINR，再通过 EESM 汇聚。

常见候选公式：`γ_eff(β)=−β ln[(1/K) Σ_{k=1}^K exp(−γ_k/β)]`，`β>0`。该表达仅供实施参考，如题设另有缩放参数或多流融合公式，严格按原题替换。使用 `scipy.special.logsumexp` 实现数值稳定计算；全载波 SINR 相同时必须恢复原值，可作为单元测试。

在有标签训练集内部进行 `β` 有界网格搜索或一维优化，并学习 `ŷ=g(γ_eff)` 的单调速率映射。连续速率使用保序回归/分段线性函数并最小化 MAE 或题设主指标；如果标签为 MCS/合法速率档位，则使用有序阈值分类，不可把 MCS 数字直接当 Mbps。避免同时让 `β` 和任意伸缩的 `g` 无约束变化造成参数不可识别；固定题设增益或约束函数复杂度，并报告 `β` 对数据划分及搜索范围的敏感性。

对比恒定预测、平均 SINR、标准 EESM 等可解释基线。输出参数值、内部独立验证误差、预测与真实图、分速率段误差以及每条待预测样本结果。未读数据之前不填写数值。

## 四、问题二：关闭 TxBF，设计新的速率估计模型

**分析**：EESM 将频点压为单值，可能损失频域衰落形状、空间秩和天线相关信息。优先采用“物理特征 + 表格机器学习”，不默认深度网络更优。

特征分四组：①载波质量：SINR 均值、方差、低分位数、低于阈值占比、EESM；②频域结构：相邻频点相关性、连续深衰落长度、相邻频点差分能量；③空间结构：`||H_k||_F²`、SVD 奇异值、条件数、主奇异值能量占比、有效秩；④只有推理时可获得的采集条件、噪声与时间差。令 `p_i=σ_i²/Σ_jσ_j²`，则有效秩代理 `r_eff=exp(−Σ_i p_i ln(p_i+ε))`，可在频域再统计均值和分位数。

先训练岭回归/随机森林作基线，主模型采用 LightGBM、XGBoost 或 sklearn HistGradientBoosting，使用分组验证、早停和有限超参数搜索。额外对照 EESM 残差模型：`ŷ=clip(g(γ_eff)+f_ML(X), y_min, y_max)`；残差须来自训练折的交叉拟合预测，避免训练内过拟合的残差泄漏。仅当表格模型明显遗漏频域局部形状且样本量足够时，再尝试 1D-CNN。

统一数据切分和指标对比 EESM、统计特征模型、EESM+特征以及残差融合模型；分别去除频域特征、空间特征、时间特征进行消融，按速率段、终端、时间差检查稳健性。

## 五、问题三：开启 TxBF 的速率估计

**分析**：发射波束赋形改变等效信道，不能原样套用关闭 TxBF 的模型。首先检查是否真的提供发送端预编码矩阵 `w_k`。如果提供，按题设由 `H_kw_k` 求等效信道并估算后处理 SINR。如果没有提供，SVD 主右奇异向量只能作为理想单流代理，不能说成真实预编码。

在“理想单流、白噪声、总功率 P_t、单位范数波束”等条件下，候选特征为 `γ_BF,k^ideal=P_t σ_1,k²/P_n`。条件不满足时只把它作为理论参考特征。附加主奇异值能量份额、奇异值比值、频点间波束方向一致性、CSI 时差、真实流数或码本（若已知）。使用开启 TxBF 的带标签样本训练独立梯度提升树；样本不足时试验用关闭场景模型预训练或共享通用特征再校准，并以一致分割严格对照。没有可配对的相同测量条件，就不宣称测得因果赋形增益。

## 六、评价、实现和提交检查

如果目标为连续速率，报告 `MAE=(1/N)Σ|y−ŷ|`、`RMSE=sqrt[(1/N)Σ(y−ŷ)²]`、`R²` 和分段误差；如果目标为档位，报告准确率、档位偏差、混淆矩阵。若题设另有主指标，应优先使用题设指标。未知标签的官方待预测集不能用于计算真实性能：必须从有标签数据中切出内部验证集。可采用分组交叉验证、时间块 bootstrap 和误差分层分析评估稳健性。

推荐实现顺序：`inspect_data.py → parse_csi.py → physical_features.py → fit_eesm.py → train_no_txbf.py / train_txbf.py → predict.py`。保存环境版本、随机种子、数据下载地址、校验和、划分索引、参数、训练日志和输出文件。最少测试：复数解析准确、dBm 与线性功率转换、均匀 SINR 下 EESM 等价性、预测行数/顺序/单位正确、无标签数据不参与拟合。
